## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` copies the repository-held `entry.png` (a JPEG in a `.png`
name, which the gate accepts) to the output directory. The image is
drawn with PIL by `draw-news-20261125-dudukuyz.py`, kept outside
this repository. Every run writes the same bytes.
